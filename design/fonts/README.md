# 離線字體

2026-09-21：由 Google Fonts CSS API 的 latin 子集取得 11 個英文字體家族，共 16 個未修改 WOFF2 檔案；各家族授權保存在 licenses/，來源精確 URL 見 sources.json。SIL Open Font License 1.1 隨站一同提供，不單獨販售字體。

包含 Inter、Lato、Montserrat、Noto Sans、Open Sans、Oswald、Playfair Display、Poppins、Raleway、Roboto、Roboto Condensed。app/fonts.css 宣告目前設計庫使用的 41 組家族／字重，變動字體共用檔案。

只包含英文字形子集，中文由裝置的 PingFang TC、Microsoft JhengHei、Noto Sans TC 或系統替代字體呈現，不連線下載；各裝置外觀可能不同。原四組字體堆疊及十組選項皆保留。CSS／JSON 匯出不會把字體二進位內容嵌入剪貼簿；採用方需自行附上本目錄和授權，或使用系統替代字體。
